
1. Системные требования

Для корректной работы проекта обязательно требуется Python версии 3.12 (на более новых версиях, таких как 3.13 или 3.14, проект не запустится из-за несовместимости используемых библиотек).
• Скачать официальный установщик Python 3.12 можно на сайте python.org.
• При установке в Windows рекомендуется отметить пункт Add python.exe to PATH.

2. Установка и запуск проекта

1. Распакуйте архив с проектом в удобную папку и откройте терминал (командную строку, PowerShell или встроенный терминал в вашей IDE, например PyCharm или VS Code) в корневой директории проекта (djangochat-master, где находится файл manage.py).
2. Создайте виртуальное окружение на базе Python 3.12:
	• Для Windows:powershell
py -3.12 -m venv venv

	• Для Linux / macOS:bash
python3.12 -m venv venv

3. Активируйте виртуальное окружение:
	• В Windows (PowerShell):powershell
.\venv\Scripts\Activate.ps1
	• В Windows (CMD):cmd
venv\Scripts\activate.bat

	• В Linux / macOS:bash
source venv/bin/activate

После успешной активации в начале строки терминала появится префикс (venv).
4. Установите необходимые библиотеки из файла requirements.txt:bash
pip install -r requirements.txt

5. Запустите локальный сервер:bash
python manage.py runserver

6. Откройте сайт в браузере, перейдя по адресу:
http://127.0.0
(Для остановки сервера нажмите в терминале комбинацию клавиш Ctrl + C.)

3. Управление сайтом через панель администратора

Администрирование контента, чатов и пользователей осуществляется через встроенную панель управления Django.
1. При запущенном сервере перейдите в браузере по адресу:
http://127.0.0
2. Введите данные для входа:
	• Имя пользователя (Логин): admin
	• Пароль: admin

Основные разделы панели управления:

• Пользователи (Users) и Группы (Groups) — просмотр зарегистрированных аккаунтов, создание новых пользователей, редактирование прав доступа и смена паролей.
• Комнаты (Rooms) — создание новых чат-комнат, редактирование их названий и управление списком участников (members).
• Сообщения (Messages) — просмотр истории переписки в комнатах, поиск и удаление отдельных сообщений.
• Новости / Статьи (News) — публикация новых записей, редактирование текстов и удаление существующих новостей на сайте.
